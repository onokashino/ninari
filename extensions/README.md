# Плагины ninari

Источники для плеера [ninari](https://github.com/onokashino/ninari). Каждое расширение - один JS-файл, который работает в песочнице приложения и видит сеть только через `ctx.fetch` к доменам из своего манифеста.

## Подключение

В ninari: Настройки → Расширения → вставить URL или путь к `dist/index.json`.

## Разработка

```bash
bun test          # контрактные тесты на живых источниках
bun run build     # dist/<id>.js, dist/index.json, dist/dubs.json
```

Расширение экспортирует `manifest` и три функции: `search`, `episodes`, `resolve` (см. `src/types.ts`). `dubs.json` сводит разные написания одной озвучки к одному ключу: ключ и алиасы записываются в нормализованном виде (нижний регистр, только буквы и цифры).

| Расширение | Озвучки | Качество |
|---|---|---|
| `anilibria` | AniLibria | до 1080p |
