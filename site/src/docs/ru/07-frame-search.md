# Поиск по кадру

Есть скриншот, но непонятно, откуда он? ninari найдёт тайтл, серию и минуту.

В **Каталоге** рядом с полем поиска:

- вставь картинку из буфера: <kbd>Ctrl</kbd>+<kbd>V</kbd>;
- или перетащи файл в окно;
- или выбери файл кнопкой **Найти по кадру**.

ninari покажет найденный тайтл с номером серии, временем и процентом совпадения. Если уверенных совпадений нет, покажет самые похожие под заголовком «Может быть, это».

## Чтобы нашлось

- Нужен кадр из самой серии. Постеры, арты и обложки поиск не знает.
- Лучше кадр без субтитров и рамок.
- Совсем новые серии появляются в базе поиска не сразу.

Поиск работает через сервис trace.moe.
