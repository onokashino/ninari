# Плеер

Внутри ninari mpv. На Windows и в Wayland видео играет прямо в окне приложения, в X11 открывается отдельным окном mpv.

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| <kbd>Пробел</kbd> или <kbd>K</kbd> | Пауза |
| <kbd>←</kbd> <kbd>→</kbd> | Назад и вперёд на 10 секунд |
| <kbd>↑</kbd> <kbd>↓</kbd> | Громкость |
| <kbd>F</kbd> или двойной клик | Полный экран |
| <kbd>M</kbd> | Без звука |
| <kbd>N</kbd> <kbd>P</kbd> | Следующая и предыдущая серия |
| <kbd>U</kbd> | Улучшение качества: включить или выключить |
| Зажать <kbd>C</kbd> | Показать оригинал без улучшения |
| <kbd>Z</kbd> | Растянуть на весь экран или вписать |
| <kbd>[</kbd> <kbd>]</kbd> | Сдвинуть звук относительно картинки |
| <kbd>Esc</kbd> | Закрыть панель, выйти из полного экрана, закрыть плеер |

## Пропуски и следующая серия

В настройках плеера включаются **Пропускать опенинги**, **Пропускать эндинги** и **Пропускать филлеры**. Если источник знает, где опенинг, а автопропуск выключен, во время опенинга появится кнопка «Пропустить опенинг».

На титрах появляется следующая серия. Она выбирается по сюжету: филлеры и пересказы по данным MyAnimeList можно пропускать.

«Продолжить» отматывает на 5 секунд назад, чтобы было понятно, где остановился.

## Звук

Эффекты включаются по отдельности:

- **Ровная громкость**: тихие реплики громче, взрывы тише.
- **Чёткие голоса**: голос выходит вперёд, музыка и шум остаются фоном.
- **Ночной режим**: громкие моменты не бьют по ушам.
- **Шумодав**: убирает шипение и гул домашней записи озвучки.
- **Наушники**: мягче разводит каналы.

## Озвучка и качество

Озвучку можно сменить прямо в плеере, место в серии сохранится. Качество выбирается автоматически самое высокое, вручную его можно снизить в меню качества.

При перемотке над полосой показываются кадры. Они собираются во время просмотра и хранятся в кэше: его можно очистить в **Настройки → Данные**.
