# Устройство проекта

ninari написан на Rust. Окно рисует GPUI, фреймворк интерфейса редактора Zed, видео играет через libmpv.

| Папка | Что внутри |
| --- | --- |
| `crates/core` | Всё, кроме окна: каталог Shikimori, библиотека, источники и плагины, плеер (управление mpv), прокси потоков, синхронизация устройств, вход в Shikimori |
| `crates/app` | Приложение: экраны, плеер, трей, ссылки `ninari://` и `shot` для отрисовки страниц в PNG |
| `extensions` | Официальные плагины на TypeScript и их сборка в `dist/` |
| `site` | Этот сайт: страницы, документация и сборщик |
| `scripts` | Запуск, упаковка релиза, установщик, шейдеры, иконки |

## Как серия попадает на экран

1. Каталог, детали тайтла и постеры приходят с Shikimori, баннеры и главные герои с AniList.
2. Каждый плагин ищет тайтл на своём сайте (`search`) и отдаёт список серий с озвучками (`episodes`).
3. Ядро сводит одинаковые озвучки с разных сайтов в одну строку по `dubs.json`.
4. При запуске серии плагин отдаёт ссылки на поток (`resolve`), локальный прокси добавляет нужные заголовки, а mpv играет.
5. Прогресс пишется в SQLite и, если включено, уходит на Shikimori и на связанные устройства.

## Песочница плагинов

Плагины выполняются в QuickJS внутри приложения. Сеть доступна только через `ctx.fetch` и только к доменам из манифеста, а приватные адреса закрыты.
