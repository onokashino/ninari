# Улучшение качества

ninari умеет дорисовывать картинку нейросетями, когда видео меньше экрана, например 720p на мониторе 1440p. Улучшение включается само, когда в нём есть смысл, а настраивается прямо во время просмотра: иконка со звёздочкой в плеере открывает панель.

## Два метода

**Anime4K** восстанавливает и увеличивает картинку в несколько проходов. У него есть режимы:

| Режим | Когда |
| --- | --- |
| Авто | Сам выбирает по высоте видео. Рекомендуется |
| A | Размытые и пережатые источники: 480p, 720p |
| B | То же мягче, меньше ореолов вокруг линий |
| C | Чистые источники: только увеличивает, не трогая детали |

**ArtCNN** аккуратнее обращается с линиями и не добавляет артефактов, но только удваивает размер, поэтому работает, когда экран заметно больше видео. Варианты: «Обычный», «Чётче» и «Мягче».

## Нагрузка

| Уровень | Для чего |
| --- | --- |
| Fast | Большинство видеокарт, включая встроенные |
| HQ | Лучше картинка, нужна дискретная уровня GTX 1660 и выше |
| Ultra | Самые большие сети, для видеокарт уровня RTX 3070 и выше |

Если видео подтормаживает, снизь уровень в панели. По умолчанию уровень задаётся в **Настройки → Плеер**, там же улучшение можно выключить совсем.

## Сравнить

Зажми <kbd>C</kbd>: пока клавиша нажата, видно оригинал без улучшения. <kbd>U</kbd> включает и выключает улучшение целиком.
