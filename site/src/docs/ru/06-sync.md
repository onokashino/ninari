# Синхронизация

## Shikimori и MyAnimeList

В **Настройки → Интеграции** у каждого сайта своя кнопка входа, она откроет браузер. После входа список синхронизируется в обе стороны:

- статусы, просмотренные серии и оценки отсюда уходят на сайт сразу;
- изменения, сделанные на сайте, приходят раз в полчаса, если они новее тех, что здесь. Просмотренные серии только добавляются, ничего не стирается.

Перенести список без входа тоже можно: на Shikimori **Импорт списка** по никнейму открытого списка, на MyAnimeList **Импортировать** после входа. Тайтлы, которые уже есть в библиотеке, не трогаются.

Если импорт принёс лишнее, **Настройки → Данные → Очистка** убирает всю библиотеку или всю историю просмотра разом. Списки на сайтах это не трогает, и синхронизация не вернёт убранное обратно.

## Свои устройства

ninari синхронизирует библиотеку, просмотренные серии, место в серии и озвучки между твоими компьютерами в одной сети. Без облака: устройства говорят друг с другом напрямую, данные шифруются.

1. На обоих компьютерах: **Настройки → Устройства → Синхронизация в локальной сети**.
2. На первом нажми **Показать код**. Код одноразовый и действует несколько минут.
3. На втором: **Связать устройство**, введи код.

После этого изменения расходятся сами, а **Синхронизировать сейчас** запускает обмен сразу. **Отвязать** разрывает связь с устройством.

## Копия библиотеки

**Настройки → Данные → Сохранить копию** сохраняет список, статусы, озвучки и серии в один файл. **Восстановить из копии** добавляет из файла только то, чего ещё нет.
