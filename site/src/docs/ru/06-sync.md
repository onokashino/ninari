# Синхронизация

## Shikimori

**Настройки → Shikimori → Войти через Shikimori** откроет браузер. После входа статусы, просмотренные серии, оценки и заметки будут уходить в твой список на Shikimori.

Без входа можно просто перенести список: **Импорт списка**, введи никнейм. Добавятся тайтлы открытого списка со статусами и сериями, то, что уже есть в библиотеке, не трогается.

## Свои устройства

ninari синхронизирует библиотеку, просмотренные серии, место в серии и озвучки между твоими компьютерами в одной сети. Без облака: устройства говорят друг с другом напрямую, данные шифруются.

1. На обоих компьютерах: **Настройки → Устройства → Синхронизация в локальной сети**.
2. На первом нажми **Показать код**. Код одноразовый и действует несколько минут.
3. На втором: **Связать устройство**, введи код.

После этого изменения расходятся сами, а **Синхронизировать сейчас** запускает обмен сразу. **Отвязать** разрывает связь с устройством.

## Копия библиотеки

**Настройки → Данные → Сохранить копию** сохраняет список, статусы, озвучки и серии в один файл. **Восстановить из копии** добавляет из файла только то, чего ещё нет.
