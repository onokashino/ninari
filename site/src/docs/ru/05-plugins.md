# Плагины

ninari не хранит и не раздаёт видео. Серии находят плагины: каждый знает один сайт, ищет на нём тайтл и отдаёт плееру ссылки на серии.

## Подключить

**Настройки → Источники → Подключить все** ставит плагины из официального каталога. Там же видно, как каждый источник работал за неделю, а «Обновить все» ставит новые версии.

Список плагинов с описаниями есть на странице [Плагины](../plugins.html).

## Безопасность

- Каждый плагин работает в песочнице: у него нет доступа к файлам и системе.
- Ходить в сеть он может только на сайты из своей карточки. Список сайтов показывается до установки.
- Файл плагина сверяется по контрольной сумме из каталога, подменённый файл не установится.

## Сторонний каталог

Каталог это файл `index.json` со списком плагинов. Подключить чужой можно двумя способами:

- **Настройки → Источники → Свой репозиторий**: вставь ссылку на `index.json` или путь к нему на диске.
- Ссылка вида `ninari://plugins?repo=<адрес index.json>` на сайте: она откроет приложение.

В обоих случаях ninari сначала покажет плагины и сайты, на которые они ходят, и установит их только после подтверждения.

Сделать свой плагин несложно: смотри [Свой источник](custom-source.html).

## Если источник не нашёл тайтл

На странице тайтла есть «Не тот тайтл?». Там видно, что нашёл каждый источник, и можно выбрать правильный вариант, найти вручную или отметить, что в этом источнике тайтла нет.
