# Search by frame

Got a screenshot but no idea where it's from? ninari finds the title, the episode and the minute.

On the **Поиск** (search) page:

- paste a picture: <kbd>Ctrl</kbd>+<kbd>V</kbd>;
- or drop a file onto the window;
- or choose a file with the button.

ninari shows the title with the episode, the time and how close the match is. When no match is sure, it shows the closest ones under **Может быть, это** (maybe it's this).

## For a good match

- Use a frame from an episode itself. Posters, art and covers aren't in the search.
- A frame without subtitles or borders works best.
- Brand-new episodes reach the search a little later.

The search runs on trace.moe.
