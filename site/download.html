Скачать установщик Каталог плагинов

Windows 10 и 11, 64 бита. Права администратора не нужны.

Как установить

  1. Запусти установщик

    Он ставит приложение только для твоей учётной записи, поэтому не спрашивает пароль администратора.

  2. Если Windows предупредит

    Установщик пока без цифровой подписи, и SmartScreen может показать «Windows защитила ваш компьютер». Нажми «Подробнее», затем «Выполнить в любом случае».

  3. Подключи источники

    При первом запуске одна кнопка подключает все плагины. Список можно перенести с Shikimori там же.
